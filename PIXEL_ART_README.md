# Pixel Art Шейдеры

Этот проект включает несколько типов pixel art шейдеров для предотвращения искажений при масштабировании.

## Типы шейдеров

### 1. Basic (Базовый)
- Простое округление координат до ближайшего пикселя
- Хорошо работает для базовой pixel art графики

### 2. Simple (Простой)
- Улучшенная версия с пороговым значением
- Предотвращает "жирные пиксели" на границах
- Рекомендуется для большинства случаев

### 3. Advanced (Продвинутый)
- Использует производные для определения области интерполяции
- Наиболее качественный результат
- Может быть медленнее других вариантов

### 4. Integer (Целочисленный)
- Автоматически переключается на целочисленное масштабирование
- Идеально для масштабов 1x, 2x, 3x и т.д.
- Основан на рекомендациях из статьи о pixel art фильтрации

## Управление

- **P** - Включить/выключить pixel art режим
- **T** - Переключить тип шейдера (Basic → Simple → Advanced → Integer)

## Как это работает

Шейдеры предотвращают искажения pixel art графики при масштабировании путем:

1. **Округления координат** до ближайшего пикселя текстуры
2. **Предотвращения интерполяции** между пикселями
3. **Сохранения четких границ** pixel art элементов

## Рекомендации

- Для лучшего качества используйте **Advanced** или **Integer** шейдеры
- **Integer** шейдер особенно эффективен при целочисленных масштабах (1x, 2x, 3x)
- Если производительность критична, используйте **Simple** шейдер

## Технические детали

Все шейдеры используют GLSL 330 и совместимы с raylib-go.
Шейдеры автоматически применяются ко всей графике в режиме 2D.
